# 林间野餐

宇涵的个人网站，以野餐场景中的收音机和放大镜进入个人说明书与创作工作台。

- 个人说明书：七个频道与完整回答。
- 创作工作台：项目文件、任务推进、参考与实验、修改记录。
- 支持项目和任务编辑、图片上传、截止日期日历、拖动任务及备份恢复。

`index.html` 包含完整界面和交互代码，`assets/` 保存初始参考图片。GitHub Pages 从 `main` 分支根目录发布。

当前发布版已包含 2026-10-12 导出的工作台草稿：4 个项目、19 个任务，包含项目紧急程度、完成状态、截止日期、参考和修改记录。新打开网站会读取这份已发布数据。

每次发布数据采用独立的浏览器草稿版本，以免旧缓存遮住新内容；之前的浏览器草稿保留在原有存储位置。

之后在网页里的修改仍保存到当前浏览器，尚未接入云端同步。同一台设备不同网站地址的数据也各自独立。若要再次发布这些修改，需要导出新的备份后更新网站。后续云端和 Hermes 接入需另行配置。
